# egpu-pascal — Hermes rules

Project conventions for this repo. Hermes auto-loads `.hermes.md` from the repo root *or any
subdirectory* (it walks parents up to the git root), which is why the rules live here rather than in
`AGENTS.md` — copy them into `AGENTS.md` as well if Claude Code/Codex should follow the same ones.

## Commits

Attribute agent-authored commits. Hermes has no built-in equivalent of Claude Code's attribution
(no injected footer, no co-author trailer), so it is a rule here instead: end the body with the
caduceus line — the mark this project's upstream README uses for Hermes — and a `Co-authored-by`
trailer naming the model that wrote it.

    ☤ Generated with Hermes Agent (<model>)

    Co-authored-by: Hermes Agent (<model>) <noreply@nousresearch.com>

- `<model>` is the model the session actually ran on (`hermes config get model`), e.g.
  `deepseek-v4.1-flash` — never a guess. This repo's results are attributed to a model the same way,
  so the model belongs in the history.
- It goes last, after any `Verified` / `Docs` sections, separated by a blank line.
- Commits a person wrote stay unmarked; this is for commits an agent wrote.
- Rewriting an already-pushed commit to add it is fine (solo repo): `git commit --amend` then
  `git push --force-with-lease`.
